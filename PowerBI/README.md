# 📊 Power BI Dashboard — Customer Churn Analysis

This folder contains the Power BI dashboard for the **Customer Churn Analysis and Retention Strategy** project.  
The dashboard provides interactive visual insights to help understand churn patterns and identify retention opportunities.

---

## 🔍 Dashboard Features
- Customer demographics overview  
- Churn rate analysis  
- Key churn drivers (tenure, charges, services)  
- High-risk customer segments  
- Insights to support retention strategy

---

## ▶️ How to Use
1. Download the `.pbix` file.  
2. Open it in **Power BI Desktop**.
